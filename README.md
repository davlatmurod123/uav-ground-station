# UAV Ground Control & Telemetry Simulator

Web-based ground station that displays simulated UAV telemetry:
altitude, speed, GPS coordinates, battery, temperature and link status.

## Tech
Python, Flask, HTML/CSS/JavaScript

## Run
pip install flask
python app.py
Open http://127.0.0.1:5000
